# Career kit

These materials go with the CampusMatch project in this repo.

| File | Use it for |
|---|---|
| [PROJECT_PITCH.md](PROJECT_PITCH.md) | Resume bullets, a 30-second and 2-minute pitch, and answers to likely interview questions about this project |
| [INTERVIEW_PREP.md](INTERVIEW_PREP.md) | 4-week coding plan, system design practice, behavioral story bank, questions to ask |
| [JOB_SEARCH_PLAN.md](JOB_SEARCH_PLAN.md) | Weekly routine, resume/GitHub/LinkedIn checklists, outreach templates |
| [application_tracker.csv](application_tracker.csv) | Track applications (open in Excel, Google Sheets or Numbers) |

## Your first week

1. **Day 1:** Read the code in `src/campusmatch/` and run `campusmatch serve`. Make one small
   change of your own and push it.
2. **Day 2:** Add CampusMatch to your resume using `PROJECT_PITCH.md`. Pin the repo on GitHub.
3. **Day 3:** Update your LinkedIn profile using the checklist in `JOB_SEARCH_PLAN.md`.
4. **Day 4:** Write 4 STAR stories (see `INTERVIEW_PREP.md`).
5. **Day 5:** Send 10 tailored applications and 5 referral messages. Log them in the tracker.
6. **Ongoing:** Code daily using the pattern plan. Review your conversion rates every two weeks.
